# Assignment 2

This Java project implements `DynamicArray`, `MyLinkedList`, and `MinHeap`. It runs four workloads and saves results to `results/results.csv`.

Requires JDK 17+ and Maven 3.8+.

Run from the project folder:

```bash
mvn compile exec:java
```

The benchmark uses one warm-up run and five measured runs. Charts are saved in `results/plots/`. See [REPORT.md](REPORT.md) for results and analysis.
